# Chrome 漫畫翻譯擴充套件

版本 0.22.2。需要本機後端，詳細安裝與授權說明見倉庫根目錄的 README 與 THIRD_PARTY。

1. 執行 `scripts/setup.ps1` 與 `scripts/start-reader.ps1`。
2. 在本機設定頁設定使用者自己的 Google AI Studio 或 Vertex AI 連線。
3. Chrome 的 `chrome://extensions` 啟用開發人員模式，以「載入未封裝項目」選擇此資料夾。
4. 打開支援的閱讀頁，按插件翻譯目前畫面；自動預翻由使用者選擇開啟。

更新程式後重新載入擴充套件。使用 ZIP 副本時，先更新副本內的檔案。管理入口可開啟本機作品資料頁；自動啟動橋接須另外執行安裝腳本。

套件不附漫畫圖片、模型、字型、閱讀記憶或共用金鑰。預設示範是本專案自製的排版測試圖。NAR 等選配模型的授權與程式碼授權分開，請參考根目錄 THIRD_PARTY。

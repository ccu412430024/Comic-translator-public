Gemini 設定

首次登入與啟用方式
  1. 在 Google Cloud 專案啟用 Vertex AI API，連結持有試用額度的帳單帳戶；登入帳戶需具備 Vertex AI User 與 Service Usage Consumer 權限。
  2. 安裝 Google Cloud CLI，開啟一般 PowerShell，執行 gcloud auth application-default login 並完成 Google 登入。
  3. 再執行 gcloud auth application-default set-quota-project YOUR_PROJECT_ID。
  4. 回到此頁套用設定，再按「測試 Gemini 連線」。

登入憑證由 Google Cloud CLI 保管在本機；不需貼上服務帳戶私鑰。試用抵扣與剩餘額度以 GCP 帳單為準，升級付費後超額仍可能收費。

使用 Gemini 時，本頁圖片與辨識文字會送至 Google API。
